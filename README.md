# Menu Yangsio (situs coba-coba)

Situs statis terpisah untuk tampilan menu bergambar Kedai Yangsio (TV / layar kedua). Tidak terhubung ke aplikasi utama dan tidak terdaftar di penyedia pembayaran.
Isi dan foto dari PDF menu Owner (27 Nov 2026). Harga manual, tidak otomatis mengikuti kasir.

Mengubah menu atau harga: edit `data.mjs`, lalu jalankan `node build.mjs` (menghasilkan `index.html`), commit, dan push ke `main`. GitHub Pages memperbarui sendiri dalam 1-2 menit.
Desain ada di `styles.css`, perilaku (gerak masuk, Mode layar TV) di `app.js`.
